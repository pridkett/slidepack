## Commiting Code

Always use conventional commits. Use a short first line that summarizes the
change, along with the scope. Then at most 2 paragraphs or six sentences
describing the commit. Make sure to add `Co-Authored-By:` along with your name
at the end of the commit message.

If you find that a commit message is going to be too long, break the commit up
to smaller chunks.

Never make merge commits. This project has a nice linear history working off `main`.
